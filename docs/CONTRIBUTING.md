# Contributing to SavannaGuard

Thank you for helping build SavannaGuard.

## Before contributing
1. Read the README.
2. Read `docs/SECURITY.md`.
3. Follow the Code of Conduct.
4. Search existing issues first.
5. Never commit passwords, API keys, private keys, tokens, or personal data.

## Development principles
Contributions should favour privacy by design, least privilege, secure defaults, open standards, transparency, accessibility, and maintainability.

## Pull requests
Explain the problem and solution, include validation/tests where practical, update documentation when behaviour changes, and keep changes focused.

Security-sensitive changes should explain the threat, assumptions, and security impact.

For privately discovered vulnerabilities, follow `docs/SECURITY.md` instead of opening a public issue.
