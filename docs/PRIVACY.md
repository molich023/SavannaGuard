# SavannaGuard Privacy Policy — draft

**Effective date:** 4 September 2026

SavannaGuard is designed around data minimisation.

### Data stored locally
Browser settings, search endpoint configuration and normal browser storage may be stored on the user's device.

### No account required
The prototype does not require a SavannaGuard account.

### No behavioural advertising
SavannaGuard does not intentionally sell browsing history or build advertising profiles.

### Network requests
Websites visited by the user necessarily receive network information required to serve content. News feeds and configured search endpoints also receive requests. A production release should document every first-party endpoint.

### VPN/Tor
SavannaGuard does not request VPN passwords. Users should use a trusted VPN/Tor client and review its privacy policy separately.

### News
The prototype reads public RSS feeds. Production should use a first-party feed relay with minimal logs and a published retention policy.

### Security
SavannaGuard should publish security advisories, dependency manifests, SBOMs and a vulnerability disclosure policy.

This document is a draft and should be reviewed by qualified privacy counsel before public launch.
