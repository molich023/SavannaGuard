Privacy Policy

Last updated: 16 September 2026

SavannaGuard is designed around local-first privacy. The web preview stores bookmarks, preferences and browsing history locally in your browser storage unless you choose to clear it.

Search and news

The current web preview uses a server-side news/search index to retrieve current public results. The project is being developed toward a first-party Savanna Search and browser security stack. Search providers and data sources may change as the system matures.

No advertising profile

SavannaGuard does not intentionally add advertising SDKs, analytics profiles or cross-site user tracking to this web preview.
