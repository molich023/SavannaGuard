# SavannaGuard Browser v0.4.0

**Africa first · Privacy first · Open web**

SavannaGuard is an open-source, privacy-first browser project. v0.4 concentrates the homepage around Savanna Search and establishes the first hardened search API layer.

### What's new
- Single centered search experience.
- History and Bookmarks removed from the homepage.
- Search input validation and safe result rendering.
- Server-side query validation and upstream timeout.
- HTTP/HTTPS URL allow-listing.
- CSP and security headers.
- African news feed with 15-minute refresh target.
- English/Kiswahili interface.
- Social-media menu and local profiles retained.

### Search-engine status
Savanna Search is not yet a fully independent search index. v0.4 provides our own search interface/API/security/ranking foundation while using upstream discovery data. The next search-engine milestone is a Savanna crawler + index + ranking pipeline.
